# Sections not compiled into either PDF

These LaTeX sections are optional or superseded material. They are kept for reference and are
not part of `conference.pdf` or `exact_sampling_networks.pdf`.

- `attention_fixed_rank.tex`: an all-temperature index at fixed affine rank built from an
  arrangement of comparison hyperplanes. The compiled papers use the append-only grid index
  instead.
- `attention_groups.tex`: exact sampling from an indexed cache with a small cover of groups.
- `tanh_series_precision.tex`: a one-variable stable scaled power-series computation, superseded
  by the two-variable bound in `tanh_rank_two.tex`.

They use the macros of `../exact_sampling_networks.tex` and are not maintained against the
compiled text.
